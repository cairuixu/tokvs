다섯 가지 가입 단계(네 거래소 모두 동일)

  1. 계정 만들기. 실제로 사용하는 이메일이나 전화번호로 가입하세요. 가급적 소셜 계정과 공유하지 않는 전용 이메일과 전용 2단계 인증을 사용하세요.
  2. 강력한 비밀번호 설정. 16자 이상, 대소문자 + 숫자 + 기호 조합, 다른 곳에서 절대 재사용하지 않기. 유출된 거래소 비밀번호는 곧 돈이 사라진다는 뜻입니다.
  3. 2단계 인증(2FA) 활성화. 보안 설정에서 인증 앱(예: Google Authenticator)을 연동하세요. 복구 키는 종이에 적어 오프라인으로 보관하세요. 휴대폰에 스크린샷으로 저장하지 마세요.
  4. 본인 인증(KYC) 완료. 신분증 앞뒷면과 얼굴 인증을 업로드하세요. KYC 없이는 일반적으로 법정화폐 입금이나 출금을 할 수 없습니다. 이는 플랫폼이 까다롭게 구는 것이 아니라 글로벌 규제 요건입니다.
  5. 아래 보안 체크리스트를 완료한 뒤에 자금을 넣으세요. 단계를 건너뛰지 마세요.

첫 시도에 인증을 통과하는 방법

  • 사진은 선명하고 빛 반사가 없으며 네 모서리가 모두 보여야 합니다. 조명이 나쁜 것이 가장 흔한 거절 사유입니다.
  • 입력한 정보는 문서와 정확히 일치해야 합니다. 이름 철자와 신분증 번호를 포함합니다. 오타를 주의하세요.
  • 얼굴 인증 시 모자와 안경을 벗고 광원을 마주 보세요. 두 번 실패하면 멈추고 한 시간 기다린 뒤 다시 시도하세요. 계속 시도하지 마세요.
  • 심사는 보통 몇 분에서 몇 시간이 걸리며, 공휴일이나 피크 시간에는 더 오래 걸릴 수 있습니다. 정상적인 일입니다.

보안 체크리스트 — 가입 직후 바로 실행하세요

  • ✅ 2FA 활성화, 복구 키 오프라인 백업
  • ✅ 피싱 방지 코드 설정(공식 이메일에는 이 코드가 포함됩니다. 코드가 없는 이메일은 가짜입니다)
  • ✅ 출금 주소 화이트리스트 활성화(자금은 미리 등록한 주소로만 출금 가능)
  • ✅ 비밀번호 관리자에 저장된 고유한 긴 비밀번호
  • ✅ 철칙을 암기했습니다. 고객센터는 절대 DM을 보내거나 '안전 계좌'로 코인을 옮기라고 요구하지 않습니다
Worth knowing:일부 국가와 지역은 규제상 특정 거래소를 이용할 수 없습니다. 가입 전에 거주 지역이 지원되는지 확인하세요(가입 페이지에서 알려줍니다). 타인의 신분증으로 절대 가입하지 마세요. 출금 심사에서 나중에 동결됩니다.
