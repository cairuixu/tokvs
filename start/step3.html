注册五步（四家通用）

  1. 注册账号。用常用邮箱或手机号注册。邮箱建议用一个专门的、开启了两步验证的邮箱，不要和社交账号共用。
  2. 设置强密码。16 位以上、大小写+数字+符号，且不要和其他任何网站重复。交易所密码泄露 = 钱直接没。
  3. 开启两步验证（2FA）。在安全设置里绑定验证器 App（如 Google Authenticator）。恢复密钥抄在纸上离线保存，不要截图存手机。
  4. 完成实名认证（KYC）。上传身份证正反面 + 人脸识别。不做 KYC 基本不能法币入金和提币，这是全球监管的统一要求，不是平台故意为难你。
  5. 做完安全清单（见下）。再去入金，别跳步。

认证一次过的技巧

  • 证件照片要清晰、无反光、四角完整，光线不足是最常见的驳回原因。
  • 填写信息必须和证件完全一致，姓名拼音、证件号别手抖打错。
  • 人脸识别时摘掉帽子和眼镜，正对光源；失败两次先退出，等一小时再试，不要连刷。
  • 审核时长一般几分钟到几小时，节假日和高峰期可能更久，属正常现象。

注册完立刻做的安全清单

  • ✅ 两步验证（2FA）已开启，恢复密钥已离线备份
  • ✅ 设置防钓鱼码（官方邮件会带这个码，没有的一律是假邮件）
  • ✅ 开启提现地址白名单（之后提币只能提到预先登记的地址）
  • ✅ 密码独立且足够长，存进密码管理器
  • ✅ 记住一条铁律：官方永远不会私聊你、不会让你把币转到"安全账户"
特别提醒：部分国家和地区受监管限制无法使用某些交易所，开户前先确认自己所在地区在服务范围内（各官网注册页会有提示）。不要用他人身份注册，后续提现审核会卡住。
