Five sign-up steps (same on all four)

  1. Create the account. Register with an email or phone number you actually use. Ideally use a dedicated email with its own two-factor authentication, not shared with social accounts.
  2. Set a strong password. 16+ characters, mixed case + digits + symbols, and never reused anywhere else. A leaked exchange password means the money is simply gone.
  3. Enable two-factor authentication (2FA). Bind an authenticator app (such as Google Authenticator) in security settings. Write the recovery key on paper and store it offline — don't screenshot it into your phone.
  4. Complete identity verification (KYC). Upload both sides of your ID plus a face check. Without KYC you generally can't deposit fiat or withdraw — it's a global regulatory requirement, not the platform being difficult.
  5. Finish the security checklist below before funding anything. Don't skip steps.

How to pass verification the first time

  • Photos must be sharp, glare-free, with all four corners visible — poor lighting is the most common rejection reason.
  • Typed details must match the document exactly — name spelling and ID number included. Watch for typos.
  • For the face check, remove hats and glasses and face a light source. If it fails twice, stop, wait an hour, and retry — don't keep hammering it.
  • Review usually takes minutes to a few hours; holidays and peak times can take longer. That's normal.

Security checklist — do this right after sign-up

  • ✅ 2FA enabled, recovery key backed up offline
  • ✅ Anti-phishing code set (official emails carry it — any email without it is fake)
  • ✅ Withdrawal address whitelist on (funds can only leave to pre-registered addresses)
  • ✅ Unique, long password stored in a password manager
  • ✅ One iron rule memorized: support will never DM you or ask you to move coins to a "safe account"
Worth knowing:some countries and regions are restricted by regulation from using certain exchanges — check that your location is supported before signing up (the registration page will tell you). Never register with someone else's identity; withdrawal reviews will freeze you later.
